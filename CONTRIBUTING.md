# Contributing

The AI2Human server itself is proprietary, so this repository accepts contributions to the **documentation and configuration** only.

Good contributions:

- fixing a typo or an out-of-date step in the docs,
- adding setup instructions for another MCP client,
- reporting a bug or a missing capability through an [issue](../../issues/new/choose).

For account, billing or plan questions, use <https://ai2human.app/contact> instead of the issue tracker. For security problems, follow [SECURITY.md](SECURITY.md).

Pull requests should change one thing, keep the existing tone, and keep every example runnable.
